Tải File Mẫu Chuẩn (Template)

Tải file mẫu có sẵn dữ liệu ví dụ của các môn học. Bạn chỉ cần mở bằng Excel, nhập thêm các dòng câu hỏi mới, lưu lại và tải lên ở Tab 1.

💾

Xuất Ngân Hàng Câu Hỏi Hiện Tại

Xuất toàn bộ 0 câu hỏi trắc nghiệm đang có trên web ra file Excel (.csv) hoặc JSON (.json) để sao lưu hoặc chỉnh sửa.

📌 Hướng dẫn điền cột MonHoc và ChuyenDe trong file Excel:

Mã cột MonHoc:
toan (Toán), van (Ngữ văn), anh (Tiếng Anh), khtn (KHTN), sudi (Sử & Địa), tinhoc (Tin học), gdcd (GDCD).
Mã cột ChuyenDe & DapAnDung:
• ChuyenDe: Điền 1, 2, 3, 4 (hoặc mã như toan-t1, hoặc nhập tên chuyên đề mới).
• DapAnDung: Điền A, B, C hoặc D.
