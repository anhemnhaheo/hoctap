☁️ Cài Đặt Lưu Tự Động Lên GitHub (Câu Hỏi & Log Điểm)

Sử dụng GitHub API để lưu trực tiếp cau_hoi_bo_sung.json và nhat_ky_diem.json vào kho code của bạn

⚠️ Chưa nhập GitHub Token. Hệ thống đang đọc dữ liệu công khai từ GitHub và lưu tạm trên máy.

Token chỉ được lưu trong trình duyệt trên máy của bạn, không bao giờ bị đẩy lên mã nguồn công khai.

⚙️ Chế độ tự động đồng bộ khi đã có Token:

📖 Hướng dẫn lấy GitHub Token trong 1 phút (Bấm để xem)
  1. Đăng nhập GitHub → truy cập: github.com/settings/tokens?type=beta → bấm Generate new token.
  2. Đặt tên Token (VD: WebHocTap8), chọn thời hạn (Expiration: No expiration hoặc 1 năm).
  3. Ở mục Repository access, chọn Only select repositories → chọn đúng kho hoctap.
  4. Mở mục Permissions → Repository permissions → tìm dòng Contents → đổi thành Read and write.
  5. Bấm Generate token, sao chép mã token bắt đầu bằng github_pat_... dán vào ô phía trên và bấm Lưu cấu hình.
